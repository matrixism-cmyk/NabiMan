# 01. 개요 (Overview)

## 1. 배경

JCIA 5G MEC 테스트베드(나주 메타허브센터)는 실증기업에게 GPU/CPU/네트워크 자원을 할당하여 5G MEC 기반 서비스 실증을 지원한다. 현재 운영은 다음과 같이 이루어진다:

- **수작업 스크립트 기반**: `operator-kit/scripts/01-init-tenant.sh` 등 Bash 스크립트를 관리자가 SSH로 직접 실행
- **분산된 관리 포인트**: Kubernetes, Rancher, Harbor, AXGATE 방화벽, MetalLB를 각각 별도 도구로 관리
- **문서화 수동**: 기업별 접속 가이드(docx)를 Python 스크립트로 생성
- **조회 어려움**: 전체 자원 현황을 보려면 여러 kubectl 명령을 조합해야 함

이는 관리자의 운영 부담이 크고, 휴먼 에러 가능성이 높으며, 실증기업 확대 시 확장성이 제한된다.

## 2. 목적

NabiMan 대시보드에 **MEC Management 모듈**을 통합하여:

1. **원클릭 테넌트 프로비저닝**: NS + Rancher + Quota + Taint + 스타터킷 자동 생성
2. **통합 가시성**: 노드/GPU/네트워크/스토리지/방화벽을 하나의 화면에서 조회
3. **휴먼 에러 제거**: 정책 기반 자동 설정 (필수 Label/Taint/NetworkPolicy 누락 방지)
4. **운영 문서 자동화**: 접속 가이드 및 자원 할당 보고서 자동 생성
5. **추적 가능성**: 모든 변경 이력(Audit Log) 보존

## 3. 적용 범위

### 포함 (In-Scope)

| 영역 | 기능 |
|------|------|
| **테넌트 관리** | 생성/수정/삭제, Quota 변경, 멤버 추가/제거 |
| **노드 관리** | 노드 현황, Taint/Label 관리, GPU 모드 전환 |
| **GPU 자원** | Slot 할당 현황, Time-Slicing 설정, Passthrough 전환 |
| **네트워크** | MetalLB IP Pool, LB 서비스 목록, Ingress 규칙 |
| **방화벽** | AXGATE NAT 규칙, proxy-arp, 공인 IP 매핑 |
| **스토리지** | Longhorn 볼륨, PVC 현황, Harbor 이미지 |
| **사용자** | Rancher 사용자, 역할 바인딩, 비밀번호 리셋 |
| **문서 생성** | 테넌트별 접속 가이드 docx/pdf 출력 |
| **Audit Log** | 모든 변경 작업 이력 기록 |

### 제외 (Out-of-Scope)

| 영역 | 사유 |
|------|------|
| 기업 워크로드 배포 | 기업이 직접 Rancher UI나 kubectl로 수행 |
| Prometheus/Grafana 대체 | 기존 Grafana 링크 제공 (임베드만) |
| 백업/복구 실행 | Velero CLI 유지, 상태만 조회 |
| 5G 기지국 제어 | 별도 벤더 WEB MANAGER 사용 |

## 5. 성공 기준 (KPI)

| 지표 | 현재 | 목표 |
|------|------|------|
| 테넌트 1개 생성 소요 시간 | 약 30분 (스크립트 + 수동 확인) | **5분 이내 (UI 클릭)** |
| 테넌트 삭제/정리 소요 시간 | 약 20분 (네임스페이스/프로젝트/LB/NAT) | **2분 이내** |
| 전체 자원 현황 파악 | kubectl 명령 10개+ 조합 | **대시보드 1개 화면** |
| 접속 가이드 문서 생성 | Python 스크립트 수동 실행 | **UI에서 다운로드 버튼** |
| 방화벽 NAT 규칙 추가 | AXGATE CLI 수동 SSH | **UI 폼 입력** |
| 신규 관리자 교육 기간 | 약 2주 | **1일** |

## 6. 제약 조건

- **NabiMan 기존 아키텍처 준수**: Rust + Actix-web, React, 단일 바이너리 배포
- **보안**: 관리자 권한 사용자만 접근 가능 (기존 NabiMan 인증 재사용)
- **네트워크**: VPN 내부망에서만 접근
- **K8s RBAC**: NabiMan이 사용할 ServiceAccount는 cluster-admin 수준 권한 필요
- **기존 operator-kit 스크립트와 공존**: 점진적 전환, 기존 스크립트 즉시 폐기하지 않음

## 7. 전제 조건

- NabiMan이 MEC 클러스터 내부 또는 VPN 접근 가능한 네트워크에 배포되어 있음
- Kubernetes API(VIP 172.20.26.239:6443) 접근 가능
- Rancher API(rancher.jcia.mec.local) 접근 가능
- AXGATE 방화벽 CLI SSH(121.147.13.228:2222) 접근 가능
- Harbor API(172.20.26.234) 접근 가능
