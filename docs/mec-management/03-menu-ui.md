#### 2.2.3 테넌트 상세 (`/mec/tenants/:id`)

**탭 구조**:
- Overview: 요약 정보
- Resources: Pods, Services, PVCs
- Quota: 현재 사용량 (프로그레스 바)
- Members: Rancher 사용자 목록
- Starter Kit: Ubuntu/VS Code 접속 정보
- Audit: 이 테넌트 관련 로그

## 3. UX 원칙

| 원칙 | 적용 |
|------|------|
| **확인 필수** | 삭제/이동 작업은 모달 확인 + 이름 재입력 |
| **위험 경고** | 노드 Taint 변경, GPU 모드 전환 시 영향 범위 경고 |
| **되돌리기 가능** | 가능한 작업은 Undo 버튼 제공 (30초 이내) |
| **로딩 상태** | 외부 시스템(AXGATE SSH) 호출은 진행 표시 |
| **낙관적 UI** | 즉시 반영 후 실패 시 롤백 표시 |
| **단축키** | `Ctrl+K` 명령 팔레트, `g+t` 테넌트 목록 이동 |

## 4. 디자인 시스템

- NabiMan 기존 디자인 토큰 재사용
- 색상 의미:
  - 초록: 정상/활성
  - 노랑: 주의 (쿼터 80%+ 사용)
  - 빨강: 위험 (쿼터 100%+, 노드 Not Ready)
  - 파랑: 정보/링크
