# Terminal fonts

Bundled so terminals look the same on every computer, with no request to
another site. Each file is the font's own release, unmodified (D2Coding and
Nanum Gothic Coding have Reserved Font Names; nothing here is subset or
converted). Licenses: the SIL Open Font License 1.1, shipped with the page
as `public/fonts/*-OFL.txt` (served at `/fonts/`).

| Font | Version | Source |
|---|---|---|
| D2Coding | 1.3.2 (2018-05-24) | https://github.com/naver/d2codingfont |
| Nanum Gothic Coding | Google Fonts | https://github.com/google/fonts/tree/main/ofl/nanumgothiccoding |
| JetBrains Mono | 2.304 | https://github.com/JetBrains/JetBrainsMono |
| Fira Code | 6.2 | https://github.com/tonsky/FiraCode |
| Cascadia Mono | 2407.24 | https://github.com/microsoft/cascadia-code |
